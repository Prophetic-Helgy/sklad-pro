# Склад ПРО — установка и запуск

Приложение для складского учёта — замена Excel-приложения «Склад ПРО 7.1».
Вся терминология сохранена: Номенклатура, Склад, Поставщики, Приход, Расход,
Списание, Реестры, Админ, Архивы, «Записать», «Новый приход».

## 1. Системные требования

- Windows 10/11 (64-bit). Python и другие программы **не нужны** — всё внутри.
- ОЗУ от 2 ГБ. Свободного места — ~300 МБ.
- Для работы в сети: общий доступ в локальной сети (один ПК — сервер, остальные — клиенты).

## 2. Форматы поставки

| Файл | Для кого |
|---|---|
| `Склад ПРО Setup 1.0.0.exe` | Установщик (появляется пункт в меню «Пуск», ярлык на рабочем столе) |
| `Склад ПРО portable 1.0.0.exe` | Портативная версия — запуск с флешки/папки без установки |

## 3. Установка

1. Запустите `Склад ПРО Setup 1.0.0.exe`, выберите папку (по умолчанию `C:\Program Files\Sклад ПРО`).
2. Дождитесь окончания установки.
3. Запустите «Склад ПРО» из меню «Пуск».

Портативная версия: просто запустите `Склад ПРО portable 1.0.0.exe` из любой папки
(лучше — своей папки, а не корня диска; данные хранятся отдельно, см. раздел 6).

## 4. Первый запуск

При первом запуске приложение спросит, как вы будете работать:

- **Локально (на этом компьютере)** — приложение само запустит сервер и будет
  работать с базой на этом ПК. Это вариант «как раньше, один компьютер».
- **В сети (сервер на другом компьютере)** — введите адрес, по которому работает
  сервер (IP или имя, например `192.168.1.10` или `192.168.1.10:8700`).

После этого откроется окно с экраном входа.

**Стартовый вход: `admin` / `1234`.** Сразу после первого входа смените пароль:
*Админ → Пользователи → admin → «Сменить пароль».*

> Пароль по умолчанию `1234` действует, пока вы его не смените. Если сменить
> не удалось — см. раздел 9, вопрос 5.

## 5. Работа в локальной сети

### Сервер (ПК склада)
1. На серверном ПК установите/запустите «Склад ПРО» и выберите **Локально**.
2. Узнайте IP сервера в сети: `Win+R` → `cmd` → команда `ipconfig`
   (ищите «IPv4-адрес», обычно `192.168.x.x`).
3. Если Windows Firewall спросит, разрешите доступ в «Частной» сети
   (приложение слушает порт **8700**).

### Клиенты (касса, менеджер)
1. На клиентском ПК запустите «Склад ПРО» и выберите **В сети**.
2. Введите адрес сервера, например `192.168.1.10:8700`.
3. Войдите со своим логином (пользователей создаёт администратор: *Админ → Пользователи*).

Настройки адреса сохраняются: при следующих запусках выбор режима не нужен.
Сменить адрес в любой момент: меню окна «Склад ПРО» → *Настройки (адрес сервера)*.

База данных **никогда не шарится по сети** — только API-запросы к серверу.

## 6. Где хранятся данные

```
%LOCALAPPDATA%\SkladPro\data\
├─ склад.db        — база данных (все данные)
├─ secret.key      — секрет для сессий (не удалять)
├─ server.log      — журнал сервера (локальный режим)
└─ backups\        — резервные копии
```

`%LOCALAPPDATA%` на вашем ПК — это `C:\Users\<Имя>\AppData\Local`.
Скопируйте папку `SkladPro`, чтобы перенести или застраховать все данные.

### Резервные копии
*Админ → Бэкап*: создание копии в один клик, список копий, скачивание,
восстановление. Рекомендуется делать копию перед крупными операциями
(импорт, инвентаризация) и хотя бы раз в неделю.

## 7. Перенос данных из «Склад ПРО 7.1» (xlsm)

1. Откройте *Админ → Миграция 7.1*.
2. Перетащите файл `Склад ПРО 7.1.xlsm` в зону импорта и подтвердите.
3. Ниже появится отчёт: что перенесено (номенклатура, поставщики, сотрудники,
   карточка предприятия), какие строки реестров стали документами,
   что пропущено (с причинами) и **сверка остатков** — расхождений быть не должно.

Реестры старого файла переносятся как проведённые документы Прихода/Расхода/
Списания, начальные остатки — документом «Начальные остатки (перенос из 7.1)».
Всё выполняется одной операцией: либо целиком, либо не выполнено вовсе
(при ошибке база не меняется).

Старые пароли сотрудников **не переносятся** (в отчёте — предупреждение);
сотрудникам выданы временные пароли, их нужно сменить.

### Обратная проверка
*Админ → Миграция 7.1 → «Скачать файл в формате 7.1»* — приложение выгрузит
текущие данные в структуру листов старого файла, его можно сверить с оригиналом.

## 8. Основные операции (кратко)

| Задача | Куда |
|---|---|
| Добавить товар | *Номенклатура → Новый* (наименование, артикул, ед. изм, категория, цена) |
| Оприходовать | *Приход* → добавить позиции → **«Записать»** |
| Отпустить в расход | *Расход* → Получил/Отпустил → позиции → **«Записать»** |
| Списать (брак и т.п.) | *Списание* → причина → **«Записать»** |
| Переместить между складами | *Перемещение* |
| Подсчёт | *Инвентаризация* — по разнице корректирует остатки |
| Остатки сейчас | *Склад* (подсветка ниже минимума, «История» — движение товара) |
| Отчёты | *Отчет по приходу/расходу/списанию* + *Отчёты* (ОСВ, Движение, Ниже минимума, ABC, Оборачиваемость) |
| Печать накладной | *Реестр расхода → печать* (макет как в 7.1) или «Открыть» документа |
| Отчёт в Excel/PDF | Кнопки «Excel» / «Печать/PDF» на экранах отчётов |

Контроль отрицательных остатков включён по умолчанию.
Отключить: *Админ → Настройки → разрешить отрицательные остатки*.

## 9. Частые вопросы

**1. Окно открылось с текстом «Подключение к серверу…» и зависло.**
Локальный режим: сервер должен запуститься за секунды. Если нет — посмотрите
`%LOCALAPPDATA%\SkladPro\data\server.log` (в логе — причина, чаще всего занят порт).

**2. Порт 8700 уже занят.**
Остановите другой экземпляр приложения. Либо задайте другой порт переменной
окружения `SKLAD_PORT` (например `8701`) и укажите его клиентам: `192.168.1.10:8701`.

**3. Клиент не видит сервер.**
- На сервере: разрешите порт 8700 в брандмауэре Windows (частная сеть).
- Проверьте с клиента в браузере: `http://<ip-сервера>:8700` — должна открыться страница входа.
- IP мог измениться (DHCP) — задайте серверу статический IP или имя в сети.

**4. Антивирус/Windows спрашивает о доступе приложения.**
Приложение локальное: сервер слушает только на этом ПК (локальный режим) или
открыт для доверенной сети (сервер). Разрешите доступ в частной сети —
в публичную сеть приложение ничего не отправляет.

**5. Забыли пароль администратора.**
Данные в `%LOCALAPPDATA%\SkladPro\data\склад.db`. Варианты: восстановить из
последнего бэкапа (*Админ → Бэкап → восстановление*, если вход ещё возможен),
или открыть `склад.db` в любой SQLite-программе (например, DB Browser for
SQLite) и сбросить поле `password_hash` пользователя — проще всего: сделать
бэкап, удалить БД и выполнить импорт/перенос заново из файла 7.1.

**6. Как обновить приложение?**
Сделайте бэкап (*Админ → Бэкап*), установите новую версию в ту же папку
(данные в `%LOCALAPPDATA%` не затрагиваются) или замените папку portable.

**7. Можно ли работать с одной базой с двух ПК локально?**
Нет: локальный режим — один ПК. Для двух и более рабочих мест используйте
схему «сервер + клиенты» из раздела 5 — это и надёжнее, и быстрее.

## 10. Состав программы

```
Склад ПРО.exe                  — оболочка (Electron)
resources/sklad-server/        — сервер (FastAPI + SQLite), запускается автоматически
resources/web/dist             — интерфейс
%LOCALAPPDATA%\SkladPro\       — данные и бэкапы (вне папки программы)
```
